# Makes the firmware-update HTTPS calls trust the same certificate store as
# the OS (Windows/macOS/Linux) instead of the bundled certifi CA list. Needed
# because some security software does HTTPS inspection with a root cert that
# Windows trusts but certifi doesn't ship, which otherwise breaks every HTTPS
# request in the Firmware tab with CERTIFICATE_VERIFY_FAILED.
truststore
